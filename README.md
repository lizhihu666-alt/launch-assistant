# Shopify批量上架工具

上架前查库存用的浏览器小工具：导入 Shopify 的库存导出文件，填入要上架的 SKC，就能看到每个 SKC 下各 SKU 的库存，并一键导出只含有货 SKU 的上架表。

数据全部在本机浏览器里处理，不会上传到任何服务器。

## 用哪个文件

| 文件 | 用途 |
|---|---|
| `Shopify批量上架工具.html` | 离线版，约 1MB。给同事用这个，双击就能打开，不需要联网。 |
| `Shopify批量上架工具_联网版.html` | 源文件，约 26KB。需要联网加载两个库，修改功能在这份上改。 |

请用 Chrome 或 Edge 打开，不要用微信等应用里的内置浏览器。

## 使用步骤

1. **导出库存**：Shopify 后台 → 库存 → 导出，选全部库存，得到一个 zip 文件。账号需要有导出权限。
2. **导入**：把 zip 直接拖进页面，不用解压。csv 也可以。
3. **选仓库**：默认选 `3PL US`，其他仓库可在下拉里切换。
4. **填 SKC 清单**：每行一个，或点“从 Excel 或 CSV 导入清单”（取第一列）。不填则列出该仓库的全部 SKC。
5. 点 **生成 SKU 库存表**，在表格里查看，可按状态筛选或搜索。
6. 点 **下载上架表（仅有货）** 导出上架用的文件。

## 输出

**上架表**（`SKU上架表.xlsx`）：只保留有货的 SKU，两列。

| SKU | 上架状态 |
|---|---|
| IML260623MGYWAP-C00003-S001 | active |

**库存明细**（`SKU库存明细.xlsx`）：SKC、SKU、颜色、尺码、可用、状态。

## 规则说明

- **SKC 和 SKU 的对应**：SKU 去掉末尾的 `-S###` 就是 SKC，例如 `IML260623MGYWAP-C00003-S001` 属于 `IML260623MGYWAP-C00003`。
- **库存取值**：取所选仓库的 `Available`（可用）数量。
- **状态**：
  - 有货：可用数量大于 0
  - 缺货：可用数量为 0（或负数）
  - 未建库存：Shopify 里该 SKU 在该仓库显示为 `not stocked`
- 清单里的 SKC 在所选仓库找不到时，会单独列出来并可一键复制。
- 尺码和颜色按导出文件里的 Option 名称（Size、Color）识别，不依赖 SKU 后缀。后缀编号和尺码的对应不统一，请以表里的尺码列为准。
